# 1.2 Interface Documentation Guidelines

> **Status: placeholder.**

To be written: the naming and documentation conventions to which every interface specified in [3. Class Interfaces](../class-interfaces/) conforms.

These conventions are fixed before the specification begins and do not vary within it: their purpose is to make an interface readable without reference to its implementation, and a convention that changed partway through the document would defeat it.

Intended scope:

- **Class names** — unique across the system, and the form they take.
- **Operation names** — identified by verbs.
- **Attribute and parameter names** — identified by nouns.
- **Error reporting** — an error is signalled by an exception, never encoded in a return value.
- **Documentation of each class** — the elements stated for every entry, and their order.

Each convention is to be given with the reason it was adopted, so that a reader can tell an intentional departure from an oversight.
