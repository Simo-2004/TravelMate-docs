# 4. Saving Trips and Companions

> **Status: placeholder.**

To be written: how to save a trip or a person so you can come back to it, and how to find and remove what you saved.

Intended scope:

- **Saving something** — the control that saves a trip or a companion, and where it appears on each screen.
- **How you know it worked** — the control changes to show the item is saved, and a short message confirms it.
- **The Saved tab** — trips and people saved together, most recent first.
- **Opening a saved item** — tapping one opens the same screen you saved it from.
- **Removing an item** — how to un-save, from the Saved tab or from the item itself.
- **When the tab is empty** — what the screen shows before anything has been saved.
- **How long saved items last** — they stay on the device until removed, including after the app is closed.
