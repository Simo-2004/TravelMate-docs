# 4.2 Coding Standards & Static Analysis

> **Status: to be reviewed.**

To be written: the conventions the source obeys, and the means by which conformance to them is established.

Intended scope:

- **Static analysis** — the activated rule set, the rules added to it, and the convention each enforces.
- **Formatting** — the formatter applied, and what it settles so that it is not settled by review.
- **Documentation comments** — the form applied to every public element, from which [4.6](./api-documentation) is generated.
- **Test suite** — the tests written during construction, and the specification each exercises.

The conventions themselves are fixed in [ODD 1.2](../odd/introduction/interface-guidelines) and are not restated; this chapter records how each is realised and which are checked automatically rather than by review.
