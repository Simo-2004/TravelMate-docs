TripStore

TripStore class

In-memory cache of the trip catalog, backed by SQLite.

Unlike the (mutable) profile store this is not a ValueNotifier: the catalog is read-only, so it is loaded once at startup and then served synchronously — keeping existing callers (including the synchronous findTripById used inside chat widgets) unchanged.
