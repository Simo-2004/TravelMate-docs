AccountRepository

AccountRepository class

Persists the login account and verifies credentials.

The username is AES-encrypted (mildly sensitive, but needs to be readable), while the password is stored only as a one-way PBKDF2 salted hash — never in a form that can be decrypted back. Depends only on the AccountDao abstraction plus injected crypto helpers, so seeding and verification are unit-testable against an in-memory fake DAO.
