TripTagCatalog

TripTagCatalog class

Canonical set of trip tags (label + colors), shared by TripCatalog and any other feature that needs to reference a real trip tag rather than an arbitrary label — e.g. a mate's preferred-trip tags, so they can be styled to match the actual trip tag they refer to.
