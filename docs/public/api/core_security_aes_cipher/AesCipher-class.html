AesCipher

AesCipher class

Authenticated field-level encryption (AES-256-GCM) used to protect sensitive profile columns before they are written to the local database.

Pure Dart — no platform channels — so the full round trip is unit-testable. Each encryptString call uses a fresh random 12-byte nonce, and the GCM authentication tag makes tampering detectable: decryptString throws if the payload was altered or the wrong key is used.
